gui is a terminal text editor with keyboard and mouse support, menus,
file selection dialogs, search and replacement, and configurable colors.
It supports UTF-8 text, nine open documents and two editing panels.
Selection uses Shift and arrow keys or mouse dragging. Undo history is
independent per document, and copy/paste share an internal clipboard.

The interface is intended for users who prefer classic menu-based terminal
editors and familiar selection shortcuts without modal editing.
The implementation uses C11 and ncursesw and includes core behavior tests.

I intend to maintain this package and will seek sponsorship for its upload.
The packaging candidate is maintained with the upstream project on GitHub.
